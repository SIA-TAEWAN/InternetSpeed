# InternetSpeed

버튼 한 번으로 현재 접속 중인 PC의 인터넷 속도를 측정하는 웹 페이지입니다.

- **측정 순서**: 핑/지터 → 업로드 → 다운로드
- **게이지**: 실시간 속도를 바늘과 원호 게이지로 표시 (0 ~ 1 Gbps)
- **측정 서버**: Cloudflare 엣지 네트워크 (`speed.cloudflare.com`)
- 설치 없이 정적 파일(HTML/CSS/JS)만으로 동작 → GitHub Pages로 바로 배포 가능

## 사용 방법

1. GitHub Pages 주소로 접속합니다.
2. **측정 시작** 버튼을 누릅니다.
3. 핑 → 업로드(약 10초) → 다운로드(약 10초) 순으로 자동 측정됩니다.

## 측정 방식

| 항목 | 방식 |
| --- | --- |
| 핑 | 빈 요청 12회 왕복 시간의 중앙값 (첫 연결 요청 제외) |
| 지터 | 연속 핑 값 차이의 평균 |
| 업로드 | 4개 병렬 스트림으로 8MB 데이터를 10초간 반복 전송 |
| 다운로드 | 6개 병렬 스트림으로 25MB 데이터를 10초간 반복 수신 |

초기 1.5초는 TCP 속도 상승 구간이므로 최종 결과 계산에서 제외합니다.

## 로컬 실행

`index.html`을 브라우저에서 바로 열면 됩니다.

## 파일 구성

- `index.html` – 화면 구조
- `style.css` – 디자인
- `speedtest.js` – 게이지 렌더링 및 속도 측정 로직
